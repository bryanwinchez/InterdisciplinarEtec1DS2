# ⚽ Mundial de Clubes 2025 — InterdisciplinarEtec1DS2

Site informativo sobre o **Mundial de Clubes FIFA 2025**, desenvolvido como projeto interdisciplinar na **Etec Doutora Ruth Cardoso** (turma 1DS2). O projeto reúne HTML, CSS e JavaScript para apresentar informações sobre os clubes participantes, jogos e curiosidades do torneio.

## 📋 Sobre o Projeto

Trabalho interdisciplinar que aborda o **Mundial de Clubes 2025**, competição histórica expandida pela FIFA. O site apresenta páginas dedicadas aos principais clubes participantes, além de seções de jogos, times favoritos e uma página "sobre" o projeto. Inclui também a documentação do trabalho em PDF.

## 🏆 Clubes em Destaque

O site apresenta páginas individuais para alguns dos clubes participantes do torneio, incluindo times brasileiros como **Botafogo** e **Atlético**, além de clubes internacionais como **PSG** (França) e **Seattle Sounders** (EUA).

## ✨ Funcionalidades

- Apresentação dos clubes participantes do Mundial de Clubes 2025
- Páginas individuais por clube com informações detalhadas
- Seção de jogos e tabela do torneio
- Sistema de time favorito interativo
- Documentação completa do projeto em PDF
